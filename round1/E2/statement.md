# E2 – Peak Voltage
**Language:** C++ · **Level:** Easy · **Points:** 20

Print the largest of `n` readings (they may be negative). The code below has bugs; fix them (keep the original structure).

**Input:** `n`, then `n` integers
**Output:** The maximum
**Constraints:** 1 <= n <= 100, |a_i| <= 10^6

**Sample input**
```
3
-5 -2 -9
```
**Sample output**
```
-2
```
